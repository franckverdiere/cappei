# Fiches de révision CAPPEI

Version web des fiches de révision CAPPEI : rapports de jury, cadre réglementaire et institutionnel, notions, publics et disciplines, index des auteurs et des sigles.

Le site se trouve dans le dossier `docs/` (pages HTML, feuille de style et un peu de JavaScript, sans dépendance externe). Il est publié avec GitHub Pages.

Le contenu vient exclusivement des documents de cours ; les petits repères gris (CL, ECR, T25…) indiquent la source, détaillée en bas de chaque page.
